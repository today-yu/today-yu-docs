# Auth 컨텍스트 정책

## 1. 이메일 인증

- 이메일 인증 시 발급되는 인증 코드는 6자리 숫자 형식이다.
- 인증 코드의 유효 시간은 3분이다.
- 인증 코드 재발급은 이미 발급된 코드가 존재할 경우 1분 뒤부터 가능하다. 
- 인증 코드 재발급 시 기존 저장된 코드에 덮어쓴다.


## 2. 일반 로그인 

- 로그인 후 인증 토큰(AccessToken, RefreshToken)을 발급한다.
- 인증 토큰 발급 시 Claim에 두 토큰이 공통으로 사용하는 식별자인 세션 ID(SessionID)를 생성하여 클레임으로 설정한다.
- AccessToken의 만료 기한은 30분으로 설정한다.
- RefreshToken의 만료 기한은 2주로 설정한다.


## 3. 로그아웃

- 로그아웃 시 기존 회원이 사용하던 AccessToken은 Blacklist Token으로 저장한다.
- 로그아웃 시 기존 회원이 사용하던 Refresh Token은 Redis 저장소에서 제거한다.
- 로그아웃은 `MEMBER` 역할(Role)을 가진 회원만 요청할 수 있게 보호된다.

## 4. 인증 토큰 재발급

- 인증 토큰 재발급은 RefreshToken을 통해서 가능하다.
- 인증 토큰 재발급 시 발생한 에러는 별도의 에러 타입을 반환하여 프론트엔드에서 인증 토큰 재발급 시도를 방지한다.
